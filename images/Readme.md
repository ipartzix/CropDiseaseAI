# Test Images Folder

## Overview

This folder is used to store images that are loaded as input data for the model during testing.

The images placed here are used to test the model's performance, predictions, and image processing capabilities.

## Usage

- Add test images to this folder.
- The model will load these images during the testing process.
- Make sure images are in the supported format before running the tests.

## Supported Formats

Common supported image formats:
- `.jpg`
- `.jpeg`
- `.png`
- `.webp`

## Purpose

This folder contains sample images used only for model testing and evaluation.
